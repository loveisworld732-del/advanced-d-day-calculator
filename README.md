# Welcome to the Advanced D-Day Calculator!

I am incredibly excited to officially share my GUI-based D-Day Calculator with the global developer community! This application features a beautiful, clean pastel-pink interface and offers advanced option-tracking capabilities that standard calculators don't support.

## 🌟 Key Features
* **Beautiful GUI Interface:** Clean, user-friendly, and highly modern pastel design.
* **Dual Language Support:** Fully accessible and beautifully localized in both **English** and **Korean (한국어)**!
* **Advanced Options:**
    * Exclude weekends (주말 제외)
    * Exclude public holidays (공휴일 제외)
    * Anniversary style counting (Includes the start date as Day 1)
    * Elapsed days mode (Tracks elapsed time from a base date when no target date is set)

#### 1. For General Users (Recommended!)
